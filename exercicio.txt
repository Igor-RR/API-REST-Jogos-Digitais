Uma empresa deseja desenvolver uma pequena API REST para gerenciamento de jogos digitais.
Cada jogo pertence a um gênero e pode estar disponível em várias plataformas.

Modelo de Dados
A aplicação deverá utilizar a seguinte estrutura:

Gênero
id
nome

Plataforma
id
nome

Jogo
id
titulo
idGenero

Relacionamentos

Um gênero possui vários jogos - OK
Um jogo pertence a um gênero - OK
Um jogo pode possuir várias plataformas - Ok
Uma plataforma pode possuir vários jogos - Ok

Objetivo

Utilizando Typescript, Prisma e SQLite, desenvolva uma API REST capaz de:
cadastrar gêneros
cadastrar plataformas
cadastrar jogos
relacionar jogos com plataformas
listar os dados cadastrados
